🦭 Adventures of Waffle

An underwater arcade-style browser game where you guide Waffle the sea lion through the ocean, dodge floating trash, and collect delicious sea snacks.

Built with pure HTML5 Canvas + JavaScript.

🎮 Gameplay

You control Waffle, a playful sea lion swimming through an increasingly chaotic ocean.

🕹 Controls

Arrow Up / Down / Left / Right – Move Waffle

Click – Start game / Continue after life lost / Close memory screens

HONK button – Honk (for vibes 🦭)

H key – Toggle hitbox debug mode

🐟 Food Types

There are two types of food:

🐠 Fish

Swim smoothly across the screen

Slight wave-like motion

Standard +200 points

🦑 Squid

Larger and floatier

Bob up and down while drifting

Animated sprite sheet

Also +200 points (for now…)

🗑 Obstacles

Floating trash and seaweed appear as hazards.

Trash drifts slowly across the screen

Seaweed grows from the ocean floor

Collision triggers:

Life lost

Boink sound

Dizzy animation above Waffle

💫 Features

🎵 Background music (loops automatically)

🔊 Honk + boink sound effects

🌀 Animated seaweed sway

🫧 Floating bubble effects

💥 Collision feedback (dizzy stars)

🧠 Memory unlock screens every 5 fish eaten

❤️ 3 life system

📈 Gradually increasing difficulty

🎯 Tight collision hitboxes

🧪 Debug hitbox toggle (H key)
